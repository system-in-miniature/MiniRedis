# MiniRedis → Redis 机制映射

权威映射与其解释的数据流一起收录在
[架构指南](architecture.md#redis)中。每一项关系都分为
**等价**、**有意简化**或**语义相反**，避免把相似名称误读成完全兼容。

建议一次追踪一组机制：

1. 命令解析与各数据类型 planner；
2. 串行执行器与不可变提交批次；
3. 过期、淘汰、事务与 Pub/Sub；
4. AOF、快照、恢复与在线重写；
5. 复制积压区、部分/完整同步与 RESP2/TCP。

阅读时同时打开[行为矩阵](behavior-matrix.md)：映射说明哪些概念可迁移到 Redis，
矩阵则给出可观察契约及其可执行测试证据。
